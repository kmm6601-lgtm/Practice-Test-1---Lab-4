Differences between HTML and Google Docs

The key difference between HTML and Google Docs is how paragraphs are presented. Google Docs uses a page layout and offers many more tools. You can directly change the font, font size, font style, and text alignment. In contrast, in an HTML file, you have to add it directly in the code, like em or strong tags for italics or bold text. For fonts, you have to embed a stylesheet, like font-family or font-size, to make the font larger or smaller. I often write my assignments in a Google Doc first so I can easily read and make more corrections. Although an HTML file has a spell checker, I find it much more efficient, so I don't have to read a long continuous line of my paragraph.
